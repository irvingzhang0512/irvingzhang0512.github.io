作者通过 OpenAI API 的 logit_bias 参数禁用 AI 常用词（如“delve”、“tapestry”），试图让文本更自然，但发现效果有限且会引发其他问题。

📡 Hacker News AI · ✍️ gmays · 2026-08-05 06:05

要点

  • 作者列举了 AI 生成文本中常见的“AI 味”词汇（如 delve、tapestry、testament），并通过 logit_bias 参数将这些词的生成概率设为 0 来禁止它们出现。
  • 实验发现，单纯禁用词汇会导致模型用其他同义词替代（如用“explore”替代“delve”），并未根本改变文风，且可能引入语法错误或逻辑问题。
  • 该方法在技术上是可行的，但效果不理想，作者认为更好的方式是优化提示词（prompt）而非粗暴禁用词汇。
  • 文章提供了一个具体的 API 调用示例和 Python 代码，展示了如何批量设置禁用词的 logit_bias 值。
