✍️ protostatis

要点

  • 应用场景：Agent 执行 web research、网页数据抓取、信息发现等轻量浏览任务，尤其适合在无 Chrome 环境或资源受限场景下为 Agent 提供网页访问能力
  • 社区趋势：星标仅 14，处于早期阶段，但 MCP 生态中浏览器自动化是热门方向，该项目与 openclaw、unchained 生态关联，定位 Agent-native 浏览器符合当前 Agent 工具化趋势
