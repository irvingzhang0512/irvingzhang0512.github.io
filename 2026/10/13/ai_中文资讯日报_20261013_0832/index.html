Agent、MCP、Skill、Cli、Model 一次讲透：老系统接入 AI 的概念地图与三条路径

腾讯程序员用团队角色类比讲清 Agent、Skill、MCP、CLI、Model 五概念关系，并给出老系统接入 AI 的三条路径与实战案例。

📡 腾讯技术工程 · 2026-10-12 17:36

要点

  • 五概念关系：Model 是大脑（推理生成）、Agent 是数字员工（目标驱动闭环执行）、Skill 是岗位手册（流程 SOP 封装）、MCP 是万能转接头（连接 AI 与外部系统的开放协议）、CLI 是对讲机（结构化交互通道）；MCP 与 CLI 可嵌套，CLI 管工具执行，MCP 管标准暴露。
  • 老系统接入三条路径：优先 API 封装为 MCP（薄封装、不改业务逻辑）、次选 CLI 包装（无 API 但有脚本，输出需结构化 JSON）、兜底浏览器自动化/RPA（最脆弱、仅过渡）；用「使用频次-业务价值」四象限排序，从高频、低风险、有 API 的系统先动手。
  • MCP 实现形式澄清：官方标准只有 stdio 和 Streamable HTTP 两种，SSE 自 2025 年 3 月起已被取代属历史方案；MCP Gateway/Proxy 属部署架构，与传输方式无关，MCP 本身传输无关。
  • 安全警示：Agent 代替人操作系统时，身份传递、最小权限、操作审计、敏感动作人工确认等，行业无通用标准方案，需一案一议。
