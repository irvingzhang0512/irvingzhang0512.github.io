代码扫描告警的 Agentic 自动修复功能正式发布

英文原标题：Agentic autofix for code scanning alerts general availability

GitHub 正式发布 Agentic 自动修复功能，让 Copilot 以开发者方式跨代码库探索、修复并验证 CodeQL 告警后提交 PR 供审查。

📡 GitHub Copilot Changelog · ✍️ Allison · 2026-10-15 21:49

要点

  • Agentic autofix 现已 GA，面向 GitHub Enterprise Cloud 上的 Code Security / Advanced Security 客户，含 data residency 场景
  • 工作方式：探索相关文件 → 生成修复 → 重跑 CodeQL 验证修复关闭告警 → 需要时迭代 → 打开 draft PR，PR 内含修复摘要、关闭原因与验证步骤
  • 使用入口：单个告警的 Assign to Copilot 按钮、安全告警列表/安全活动中最多一次选 25 个告警批量修复、以及 REST API 指定 assignees 为 [“copilot-swe-agent[bot]”]
  • 访问与计费：需企业管理员在 Advanced Security policies 中开启 Agentic autofix 策略，且需配置 Copilot 计费方式；消耗 Code Security 预算中的 AI Credits 与 GitHub Actions 分钟数

⭐ 8.0 · 必读
💡 GitHub 官方 Agentic 代码修复工具 GA，你作为 Agent 新手可了解其工作流与验证闭环，但更偏安全扫描场景，非核心学习材料
