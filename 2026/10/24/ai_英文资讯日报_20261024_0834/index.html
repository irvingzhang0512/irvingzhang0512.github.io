用量指标 API 新增来自 OpenCode 等工具的用量统计

英文原标题：Usage metrics API adds usage from tools like OpenCode

GitHub Copilot 用量指标 API 新增 totals_by_client 数组，可统计 OpenCode、Claude Code、Codex 等非 IDE 工具的模型请求、会话和 token 用量。

📡 GitHub Copilot Changelog · ✍️ Allison · 2026-10-24 07:42

要点

  • 新增 totals_by_client 数组，覆盖 enterprise、organization 及对应用户级 1 天/28 天报告，按客户端工具（opencode、claude_code、codex、zed、copilot_cli 等）统计 request_count、session_count、token_usage
  • 每个客户端条目内含 totals_by_model 细分，并带 model_selection_mode 区分模型是 user_selected、auto 还是 product_selected
  • 该功能解决非 IDE 工具不发编辑器遥测导致用量缺失的问题，改为服务端计数，帮助做工具支持与治理决策
  • 注意 request_count 统计的是模型调用次数而非提示次数，一次提示可能触发多次模型调用；客户端身份按集成 ID 尽力识别，非验证身份
