要点

  • Claude Code 的 Agent Loop 是单线程主循环：模型输出含 tool_use 就执行工具并回填结果，直到模型给出纯文本回复才结束；复杂度全在工具、权限、hooks、自动压缩和子 agent 上

📡 V2EX 技术 · ✍️ L1ch404 · 2026-10-28 13:57

要点

  • 作者是 Java 后端开发，发现 Cursor/Copilot 等 AI 编码工具的核心短板：AI 只根据代码推测结果，几乎不运行代码，导致实际运行结果不达预期、编译不通过、排错时被噪声带偏钻牛角尖
  • joLink 用 Python 开发，MCP 提供执行能力（启动项目、debug），Skill 教 Agent 如何使用这些能力，加上全局规则要求 AI 以「事上磨练」方式写代码，写完实际运行拿证据再调整，而非提前解决所有问题
