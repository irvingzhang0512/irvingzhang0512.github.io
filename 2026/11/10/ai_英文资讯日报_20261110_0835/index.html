Claude Code 正意外将机密泄露到 GitHub 各处

英文原标题：Claude Code is accidentally exposing secrets all over GitHub

Claude Code 的设置文件处理存在疏漏，导致用户在执行自动化命令时嵌入的数据库密码、API 令牌等敏感信息被提交到公开 GitHub 仓库。

📡 Ars Technica · ✍️ Kyle Orland · 2026-11-10 01:24

要点

  • 安全公司 Apiiro 在 GitHub 公开仓库的 Claude Code 设置文件中发现数千个泄露的机密，包括数据库密码、API 令牌和 root 登录凭证
  • 泄露源于用户选择「Yes, and don’t ask again」批准自动化 shell 命令时，命令原文（含敏感信息）被写入本地 .claude/settings.local.json 文件
  • Anthropic 文档声称该文件会被加入开发者全局 .gitignore，通常可防止被公开共享，但实际仍有大量泄露发生
  • 若设置文件仅停留在用户本地机器，本身不算严重安全问题，真正的风险在于该文件被误提交到公开仓库

⭐ 8.0 · 必读
