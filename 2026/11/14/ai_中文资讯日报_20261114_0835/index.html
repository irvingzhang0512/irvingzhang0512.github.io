要点

  • 问题定位：Coding Agent 反复读代码、改程序、跑测试，历史 observation 在 SWE-bench Verified 上占总 token 的 45.7%、在 Terminal-Bench 上最高占 67.8%；长上下文导致每一步调用都要重新计费，因此压缩 observation 是降低这类 Agent 成本的主要途径。

  • 实验结果：在三个 Agent 模型上，总 token 平均下降 33.0%，PASS@1 从 69.0% 升至 71.0%，交互步数从 56.5 降到 51.2；对照 LLMLingua-2、SWE-Pruner、LongCodeZip 等基线，CoACT 是总 token 最低的方法，说明「只压短单步 observation」不等于降低整任务开销。

NeurIPS 2026 Oral | MIT等提出ELD：从能量分布破解合成数据预训练质量预测

MIT 与 TUM 在 NeurIPS 2026（Oral）提出 ELD/pELD：用真实图像能量分布（负对数似然谱）的 Wasserstein-1 距离来审计和筛选合成预训练数据，比 FID、LPIPS、Recall 更能预测下游自监督表征质量。

📡 我爱计算机视觉 · 2026-11-14 00:01

要点

  • 核心洞察：自然图像在概率密度曲面上横跨从高似然平滑场景到低似然致密纹理的宽能谱，只追求“平均逼真度高”会造成模式坍缩；两个 FID 近乎相同的合成数据集，能量分布可能完全不同，下游迁移表现也随之悬殊。
  • 方法：将真实/合成样本输入已归一化的真实图像密度模型得到标量能量，用两组一维能量分布的 Wasserstein-1 距离定义 ELD；再用概率积分变换做分位数标定得到 pELD（0–1、对单调变换不变），计算只需排序 + CDF 差分，成本极低。
  • 三类失配画像：噪声型（能量右偏、长尾低似然，如高斯/Perlin/FractalDB）、过度聚集型（高 CFG 扩散样本，能量展宽比过小）、宽域但偏移型（StyleGAN3、程序纹理，形态或均值偏离真实峰值）。
  • 实验：在 DINO/ViT-S 自监督设定下，pELD 与线性探测、全参微调、ImageNet-C/A 表现强负相关（|ρ|≈0.9）；留一数据集交叉验证 MAE 仅 0.82 个百分点，优于 FID(0.91)、LPIPS(1.67)，并可直接指导离线数据重采样与混合比例优化。
