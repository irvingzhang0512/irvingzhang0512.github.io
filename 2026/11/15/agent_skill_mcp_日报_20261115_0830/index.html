Rorogogogo/keymule

Keymule 是一个用 Rust 写的本地密钥库 + MCP Server，让 Claude Code 等编码 Agent 能”使用”API token 和密码完成鉴权，但全程看不到明文——给 Agent 上”手”的同时不泄密，思路值得借鉴。

✍️ Rorogogogo

要点

  • 技术亮点：把凭据锁在本地 keychain（系统钥匙串）里，通过 MCP Server 暴露”代为调用”的能力而非暴露明文；配合 paste-to-save hook，你在终端粘贴 token 的瞬间就被截获并存入密钥库，省掉手动配置环境变量的步骤，属于”最小权限 + 凭据不落地上下文”的一种工程实现。
  • 应用场景：直接冲着 Agent 编码工作流里的真实痛点——让 Claude Code 跑 curl、调 GitHub/云厂商 API、执行部署脚本时需要 token，但把 token 写进 .env/对话上下文就等于泄露；适合需要给 Agent 开放真实凭据权限的本地开发场景。
  • 社区趋势：⭐0、单作者、Rust 新生项目，属于 MCP 生态里”Agent 凭据管理”这一正在冒头的小众方向（同类还有 1Password/Vault 的 MCP 封装）；MCP + Claude Code 生态是当下热点，但该项目未经任何社区验证，成熟度与安全性需自行审阅源码后判断。
  • 阅读建议：对你而言价值在于”Agent 如何安全持有凭据”这个设计模式，而非直接生产使用；建议把它当成一个 200 行级别的 MCP Server 实现范例来读，理解 MCP tool 如何封装敏感操作，比照搬更划算。

⭐ 7.5 · 选读

  • 应用场景：日常在多个编码 Agent 之间切换的开发者，希望把偏好、项目上下文写成一份共享记忆，让每个 Agent 都能读到；属于个人工作流层面的效率整合，而非通用基础设施。
