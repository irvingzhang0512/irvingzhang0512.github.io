📡 RadarAI · ✍️ X：OpenAI Developers (@OpenAIDevs) · 2026-11-20 07:56

要点

  • 在 Responses API 中，使用 GPT-6.2 的 Agent 可以复用之前的推理项，进而用更少的 token 获得更好的结果，并提高缓存命中率。
  • 从最新前沿模型开始，每个推理项都与此前的对话历史绑定；因此不能独立看待某个推理项。
