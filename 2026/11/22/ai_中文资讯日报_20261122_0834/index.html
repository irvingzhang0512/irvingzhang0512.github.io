8万条群聊消息做成考卷：腾讯元宝×KCL发布首个基于群聊构建的Agent记忆基准

腾讯元宝联合伦敦国王学院发布 GroupAssistBench——首个基于真实群聊（50 个群、80,299 条消息、2,395 道题）构建的 Agent 记忆基准，区分”记忆召回（L1）”与”记忆使用（L2 开放式服务）”两层能力。

📡 量子位 · 2026-11-21 17:52

要点

  • 基准设计：L1 考事实召回（1,374 题），L2 考开放式服务完成度（1,021 题），并按单条记忆 / 多记忆整合 / 更新与冲突（M1–M3）划分依赖类型；用”提供 vs 不提供历史”筛选出真正依赖记忆的题目，并设记忆锚点与历史截止点防止模型偷看答案。
  • 核心发现：记忆”找得到”不等于”用得好”。EverMemOS 在 L1 召回 0.621 高于完整上下文 0.570，但 L2 服务只有 0.247，远低于完整上下文 0.431；14 组配置对比显示检索增强并不自动带来更好的服务表现。
  • 失效归因：追踪 497 条配对记忆发现，L1 召回成功却在 L2 未被有效使用的记忆中，约 36% 根本没进入 L2 模型输入（用户请求”帮大家安排一下”缺少检索线索），约 64% 虽进了输入但未被回答真正应用（模型不知道如何把证据变成约束）。
  • 可复用干预：RER（关系证据整理，串联人物/事件/时间/决定关系）与 ACB（把事实转成有主体、范围和有效状态的回复约束）两种轻量机制，组合后让 LightMem / xMemory / EverMemOS 的 L2 分数相对基线分别提升 7.03 / 4.64 / 4.43 个百分点；论文、代码、数据集（GitHub + HuggingFace）均已开源。
